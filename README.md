# SoulReaper

一款思维方式蒸馏工具，解决普通人难以快速学习顶尖人物思维模式的痛点。用户输入目标人物名字，工具会自动完成调研、提炼、验证全流程，生成其思维技能，让用户可复用马云、马斯克等的思考逻辑，低门槛掌握高效决策与问题解决方法，适配学习、职场决策等场景。

## 架构

```
目标输入
    │
    ▼
┌─────────────────────────────────┐
│        维度分解引擎               │
│  背景 · 决策 · 思维模型          │
│  哲学 · 领导力 · 失败反思        │
└──────────┬──────────────────────┘
           │
           ▼
┌─────────────────────────────────┐
│      6 Agent 并行调研层          │
│  ┌─────┐ ┌─────┐     ┌─────┐  │
│  │Agent1│ │Agent2│ ... │Agent6│  │
│  └──┬──┘ └──┬──┘     └──┬──┘  │
│     └────────┬───────────┘      │
└──────────────┼──────────────────┘
               │
               ▼
┌─────────────────────────────────┐
│         蒸馏层                   │
│  思维模式 · 决策框架 · 心智模型  │
│  关键洞见 · 完整分析             │
└──────────────┬──────────────────┘
               │
               ▼
        结构化 JSON 输出
```

## 工具

| 工具 | 作用 |
|------|------|
| `sr_search` | 搜索互联网 |
| `sr_extract` | 提取网页正文 |
| `sr_parallel_research` | 6 Agent 并行调研 |
| `sr_distill` | 思维方式蒸馏 |
| `sr_analyze` | 端到端全流程 |

## 蒸馏模式

- **thinking-pattern** — 提取核心思维模式
- **decision-framework** — 提取决策框架
- **mental-model** — 提取心智模型
- **key-insights** — 提取关键洞见
- **full-analysis** — 完整综合分析（推荐）

## 快速开始

一条命令完成全部工作：

```
sr_analyze(target: "Elon Musk")
```

等价于：

```
sr_parallel_research(target: "Elon Musk")
sr_distill(source_text: "...", mode: "full-analysis")
```
